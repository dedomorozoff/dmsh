# Следующий батч улучшений dmsh

## Обзор

На основе анализа кода предлагаю 6 независимых улучшений, которые значительно повышают удобство использования.
Каждое улучшение атомарное — их можно реализовывать по одному или все сразу.

---

## Предлагаемые улучшения

### 1. 🧠 Multi-turn контекст разговора в REPL

**Проблема:** Каждый запрос к LLM отправляется без истории предыдущих ответов.
Пользователь не может написать «сделай то же самое, но для папки tmp» — модель не помнит предыдущий ответ.

**Решение:** Хранить в `session` скользящее окно последних N пар (запрос → ответ) и передавать их в `prompt.Context`.

**Изменения:**
- `internal/cli/session.go` — добавить поле `turns []Turn` (запрос + ответ модели)
- `internal/prompt/context.go` — добавить `RecentTurns []Turn` в `Context`, включить в системный промпт
- `internal/cli/session.go` — добавлять ответ в `turns` после каждого успешного `askStream`
- Ограничение: последние 5 пар (configurable через `/context N`)

**Польза:** Пользователь может уточнять команды итеративно, как в чате.

---

### 2. 📎 `/alias` — пользовательские алиасы для часто используемых запросов

**Проблема:** Нет способа сохранить часто используемые запросы (например, «покажи занятые порты»).

**Решение:** Новая slash-команда `/alias` для управления алиасами, хранящимися в конфиге.

**Команды:**
```
/alias                        # показать все алиасы
/alias ports="покажи занятые порты"  # добавить алиас
/alias -d ports               # удалить алиас
ports                         # выполнить алиас прямо из REPL
```

**Изменения:**
- `internal/config/config.go` — добавить `Aliases map[string]string`
- `internal/cli/repl.go` — обработка `/alias` в `handleSlash`, подстановка алиасов в `handleTurn`
- `internal/cli/repl.go` — автодополнение имён алиасов в `slashCompleter`

---

### 3. 📤 `/export` — экспорт команды в файл или буфер обмена

**Проблема:** Сгенерированную команду нельзя быстро скопировать. Помощь (`help` режим) показывает её, но нет быстрого способа сохранить.

**Решение:** `/export last` копирует последнюю команду в буфер обмена (Windows: `clip`, Linux/Mac: `xclip`/`pbcopy`), `/export last > file.sh` — в файл.

**Изменения:**
- `internal/cli/repl.go` — добавить `/export` в `handleSlash`, использовать `s.recent` для получения последней команды
- Кросс-платформенный helper: `copyToClipboard(text string) error`
- Добавить `/export` в список slash-команд и автодополнение

---

### 4. 📊 `/stats` — статистика сессии

**Проблема:** Непонятно, сколько запросов было отправлено, сколько команд выполнено, какие были ошибки.

**Решение:** Команда `/stats` выводит статистику текущей сессии.

**Вывод:**
```
Session stats:
  Started:       2 min ago
  Requests:      7
  Commands run:  5  (4 via LLM, 1 direct)
  Errors fixed:  1
  Current mode:  ai
```

**Изменения:**
- `internal/cli/session.go` — добавить `stats SessionStats` (startTime, requestCount, commandCount, errorFixCount)
- Инкрементировать счётчики в `addRecentAndHistory`, `runCommandWithCorrection`
- `internal/cli/repl.go` — обработка `/stats` в `handleSlash`

---

### 5. 🔗 Поддержка stdin pipe в one-shot режиме

**Проблема:** Нельзя передать вывод команды напрямую в dmsh:
```bash
cat error.log | dmsh "что здесь не так?"
```

**Решение:** Если stdin не TTY и данные есть, автоматически добавлять их как контекст к запросу.

**Изменения:**
- `internal/cli/oneshot.go` — проверять `isTerminal(os.Stdin)`, если нет — читать stdin, добавлять в `userInput` как `\nContext:\n<stdin>`
- `internal/prompt/context.go` — добавить поле `StdinContext string` в `Context`
- `internal/prompt/prompt.go` — включать `StdinContext` в системный промпт

---

### 6. 🔁 Повторное выполнение последней команды (`/retry`)

**Проблема:** Если команда завершилась ошибкой и auto-correction не помог, нет способа попросить модель попробовать ещё раз с другим подходом.

**Решение:** `/retry` повторно отправляет последний запрос с инструкцией «предыдущий подход не сработал, придумай альтернативу».

**Изменения:**
- `internal/cli/session.go` — хранить последний `userInput` в `session.lastInput`
- `internal/cli/repl.go` — обработка `/retry` в `handleSlash`
- Генерировать новый запрос с контекстом: `"Alternative approach needed: " + lastInput`

## Открытые вопросы

> [!IMPORTANT]
> Какие улучшения реализовать? Можно выбрать все или подмножество.

> [!NOTE]
> Multi-turn контекст (п.1) потребует небольшого изменения формата промпта — нужно убедиться, что модель корректно обрабатывает историю. Стоит начать с окна из 3 пар, чтобы не раздувать контекст.

> [!NOTE]
> Stdin pipe (п.5) — самое практически полезное улучшение для использования dmsh в pipeline-сценариях (анализ логов, объяснение вывода команд).
